How it works
  1. On the server you will work from, choose Controller. It needs a licence.
  2. On each other server, choose Managed server. No licence is needed there.
  3. On the controller, open Managed servers and follow the steps under Add a server.

A server has only one role. To switch between controller and managed server, first remove its servers (on a controller) or end its controllers (on a managed server). Choosing Off pauses Multi-Server Manager but keeps its connections. To end a connection for good, remove the server on the controller's Managed servers page, or end the link on the managed server's Controllers page.

Using the command line

If the panel cannot be used, root can do the same on the command line: /usr/local/CyberCP/bin/python /usr/local/CyberCP/multiServer/msctl.py status
