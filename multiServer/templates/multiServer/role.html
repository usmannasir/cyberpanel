Change the role

  • Off: Multi-Server Manager is not used on this server.
  • Controller: this server manages other servers. It needs a Multi-Server Manager licence.
  • Managed server: a controller that you allow manages this server. No licence is needed here.

A server cannot be both. To change between controller and managed server, first remove its servers or end its controllers.

Off stops Multi-Server Manager on this server but keeps its links: with the same role again they work as before. To end a link for good, end it on the Controllers page (managed server) or remove the server on the Nodes page (controller) first.
