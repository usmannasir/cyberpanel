How it works
  1. On the server you will work from, choose Make this the controller. It needs a licence and two-factor login.
  2. On each other server, choose Connect this server to a controller, enter the controller's address and copy the code.
  3. On the controller, open Managed servers and paste the code. The server is connected at once.

After you have entered your password here, you are not asked again for 15 minutes in this session.

Using the command line
